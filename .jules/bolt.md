## 2025-05-14 - [Artificial Delays in PublicApi Endpoints]
**Learning:** Several PublicApi endpoints (CatalogItemListPaged, UserList, RoleList) contained `await Task.Delay(1000, ct);` calls, likely used to simulate network latency during development. These artificial delays significantly slowed down integration tests and real-world API responsiveness. Additionally, some Identity-related endpoints were using synchronous `.ToList()` calls on `IQueryable` from `UserManager` and `RoleManager`, which could block threads under high load.
**Action:** Always scan for `Task.Delay` in API endpoints and replace synchronous database operations with their asynchronous counterparts (`ToListAsync`) using `Microsoft.EntityFrameworkCore`. Removing these delays and improving asynchronicity reduced `PublicApiIntegrationTests` execution time from ~16s to ~7s.
