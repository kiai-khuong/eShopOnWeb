## 2025-02-15 - Artificial Delays & Synchronous Database Queries in PublicApi Endpoints
**Learning:** Multiple PublicApi endpoints (such as `CatalogItemListPagedEndpoint`, `UserListEndpoint`, and `RoleListEndpoint`) contained hardcoded artificial `Task.Delay(1000, ct)` calls that severely slowed down API response times and degraded overall test suite performance. Additionally, performing synchronous database queries like `.Users.ToList()` and `.Roles.ToList()` on ASP.NET Core Identity managers blocks precious ASP.NET Core thread pool threads, increasing thread starvation risk under high loads.
**Action:** Remove the artificial 1-second delays and convert synchronous Identity queries to utilize asynchronous `.ToListAsync()` from Entity Framework Core (`using Microsoft.EntityFrameworkCore;`) for significantly faster response times and non-blocking asynchronous execution.
