## 2025-02-12 - PublicApi Endpoints Artificial Delays & Synchronous Identity Queries
**Learning:** Found multiple PublicApi endpoints (`UserListEndpoint`, `RoleListEndpoint`, and `CatalogItemListPagedEndpoint`) that had artificial `Task.Delay(1000)` calls inserted to simulate network latency, which severely degraded response times and test suite duration. Additionally, both `UserListEndpoint` and `RoleListEndpoint` executed synchronous `.ToList()` database queries on Identity managers. This causes thread pool starvation and blocks execution threads unnecessarily.
**Action:** Removed all `Task.Delay(1000)` calls, added `using Microsoft.EntityFrameworkCore;`, and updated synchronous queries to use `.ToListAsync(ct)`. This dramatically improves response times, reduces test suite duration from 16 seconds to around 4 seconds, and ensures asynchronous database queries.
