## 2025-05-15 - [Efficient Read-Only Queries with AsNoTracking in Specifications]
**Learning:** In eShopOnWeb, many database queries for the catalog and filters are read-only. Using `AsNoTracking()` in Entity Framework Core via the Specification pattern significantly reduces memory usage and improves performance by bypassing change tracking overhead. However, it should only be applied to specifications that are strictly for read-only purposes to avoid side effects in services that might expect tracking for updates.
**Action:** Always prefer `AsNoTracking()` for specifications used in UI-specific services like `CatalogViewModelService` or for generating counts and dropdown lists. Avoid applying it to generic specifications (like `CatalogItemsSpecification`) that might be reused in write-heavy contexts.
