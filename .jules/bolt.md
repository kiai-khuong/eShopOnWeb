## 2025-02-18 - Removing Artificial Delay and Converting Synchronous EF Core Queries to Async in Public API Endpoints
**Learning:** Found artificial `Task.Delay(1000, ct)` calls in multiple `PublicApi` endpoints (UserList, RoleList, CatalogItemListPaged), simulating network latency. In addition, identity/role endpoints were querying SQL databases synchronously via `.Users.ToList()` and `.Roles.ToList()`. Removing the delays and switching to asynchronous `.ToListAsync(ct)` yields a huge, measurable performance boost.
**Action:** Always scan API endpoints for simulated latency or blocking database calls. Removing artificial delays and using proper EF Core async extensions reduces execution times for integration/functional tests significantly (e.g., PublicApiIntegrationTests execution time was cut in half, from ~16s down to ~8s).
